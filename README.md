# JIYYAD TOOLS — WhatsApp Channel Vote

Struktur:
- api/vote.js — proxy API untuk Vercel
- public/ — HTML, CSS, JS
- server.js — untuk localhost/VPS Express

Jalankan lokal:
npm install
npm start

Buka http://localhost:3000

Deploy Vercel: upload seluruh folder; endpoint /api/vote otomatis aktif dari api/vote.js.
API key dan creator disembunyikan di server.
